# دعوات | DAWAT

منصة مستقلة لبطاقات الدعوات والمناسبات العربية. تظهر التصاميم داخل الموقع نفسه، ويجري تعديل البيانات وتصدير البطاقة دون نقل الزائر إلى أي منصة أخرى.

## افتح المنصة

- https://q8-ux.github.io/dawat-platform/
- المكتبة: https://q8-ux.github.io/dawat-platform/#/templates
- المحرر: https://q8-ux.github.io/dawat-platform/#/studio
- الدعوات المتحركة: https://q8-ux.github.io/dawat-platform/#/motion

## النسخة المنشورة

- **20 ملف تصميم SVG فعلياً** بمقاس **1080 × 1920 (9:16)**، تعرض الصور مباشرة في المكتبة والمحرر.
- أولوية العرض: **دعوات الزواج وعقد القران والخطوبة**، ثم المواليد والتخرج والتهاني.
- تغيير التصميم مباشرة داخل المحرر مع النص العربي والأسماء والتاريخ والمكان.
- قالب **دعوة ويب تفاعلية** كامل: صفحة عربية RTL متجاوبة، خريطة اختيارية، حتى أربعة أرقام واتساب، مشاركة وQR، ويبدأ دون بيانات أشخاص.
- ثلاثة أساليب للدعوات المتحركة: نسيم ناعم، بريق احتفالي، افتتاحية سينمائية، مع خيار البطاقة الثابتة.
- معاينة وإيقاف واستئناف وإعادة عرض؛ يحفظ أسلوب الحركة والمدة مع الدعوة وروابطها.
- تنزيل فيديو عمودي 1080 × 1920 بلا صوت بمدة 8 أو 12 أو 16 ثانية. MP4 عند دعمه أو WebM، وكل المعالجة داخل المتصفح.
- تنزيل PNG 1080 × 1920، طباعة PDF، رابط مشاركة ورمز QR.
- خطوط أميري والقاهرة ومكتبة QR مستضافة داخل المشروع؛ لا يقرأ سكربت خارجي بيانات الدعوة.
- مسودات ونسخ احتياطية JSON تحفظ محلياً بالمتصفح. لا توجد قاعدة حسابات سحابية.
- لا تظهر علامات أو أسماء خدمات تصميم خارجية ولا روابط مغادرة إلى مكتباتها داخل الموقع.

## المصدر والحقوق

الموجود بالواجهة العامة هو **ملفات فنية أصلية مستضافة في هذا المستودع**؛ ليست ملفات قوالب احترافية تابعة لطرف ثالث. يوجد أرشيف روابط وبيانات مصدر قديمة في `data/` و`scripts/` للاحتفاظ بالسجل الفني، لكنه **لا يُضمّن في ملفات الموقع المنشور** ولا يتضمن صوراً قابلة لإعادة نشرها. لا تُستخدم ملفات المستخدم أو مشاريعه الخاصة.

