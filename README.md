# دعوات | DAWAT

منصة عربية مستقلة لتصميم دعوات المناسبات والأفراح.

- استوديو عربي RTL و12 قالباً قابلاً للتعديل
- تصدير بطاقات PNG وPDF عبر الطباعة
- مشاركة رابط الدعوة ورمز QR
- يعمل الإصدار الأول داخل المتصفح (localStorage)

> تنبيه: لا توجد في هذه النسخة حسابات سحابية أو قاعدة بيانات للحضور أو بوابة دفع. مشاركة الدعوة تشمل بياناتها النصية في الرابط. لا تضع بيانات خاصة في روابط عامة.

المشروع مستقل تماماً، ولا يعتمد على أي مشروع آخر.

راجع مجلد `site/` للتطبيق ومجلد `tests/` للاختبارات. صفحة النشر ستعمل عبر GitHub Actions بعد تفعيل GitHub Pages من إعدادات المستودع.
