# دعوات | DAWAT — مكتبة Canva العامة

**الموقع:** https://q8-ux.github.io/dawat-platform/

## الواجهة العامة الحالية
- **20 بطاقة مرجعية من قوالب Canva العامة فقط**، تتضمن الأسماء الحقيقية للقوالب والعناوين الرسمية للبحث عنها داخل مجموعاتها على Canva.
- ست فئات للمناسبات: الزفاف، الخطوبة، التخرج، المواليد، أعياد الميلاد، والتهنئة.
- البحث والتصفية حسب المناسبة والاسم.
- تفتح البطاقات مجموعات Canva العامة في تبويب منفصل **بدون الوصول إلى حساب المستخدم أو مشاريعه**.
- **لا توجد صور أو مواد Canva معاد استضافتها في هذه المنصة**، ولا نسخ للقوالب المرخصة للتحميل من الموقع.

## التوافق مع ترخيص Canva
هذه مكتبة روابط لمجموعات Canva، وليست نسخة من قوالبها. اسم القالب يظهر داخل البطاقة ليساعد المستخدم على العثور عليه ضمن المجموعة الرسمية. استعمال القوالب وتحريرها وتنزيلها يتم في Canva ووفق شروطها.
الملكية أو الاشتراك أو التصريح بالوصول للحساب لا يمنح بالضرورة حق إعادة توزيع القوالب أو نسخها داخل تطبيق منافس. لم نستخدم أي تصاميم خاصة أو ملفات من مشاريع أخرى.

## وظائف قديمة احتفظنا بها دون عرضها ضمن المعرض العام
لمنع فقد الملفات المحفوظة: بقيت مسودات الدعوات السابقة وروابط المشاركة العاملة ومسار تعديل الدعوات المحفوظة، لكن المعرض العام الآن يعرض **Canva فقط**. هذه الميزات تحفظ البيانات محلياً ولا تتضمن قاعدة سحابية أو RSVP مركزي.

## الفحص والنشر
تعمل اختبارات القوالب ومسارات الروابط ونشر GitHub Pages تلقائياً مع كل تعديل على الواجهة.
قائمة المراجع: `assets/canva-public.js`، وتصميم الدليل: `assets/canva-public.css`.
