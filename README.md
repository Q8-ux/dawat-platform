# دعوات | DAWAT

استوديو مستقل لتصميم ومشاركة دعوات الأفراح والمناسبات، عربي RTL ويعمل على الجوال وسطح المكتب. لا يعتمد على أي مشروع آخر.

**الموقع:** https://q8-ux.github.io/dawat-platform/

## ما هو منفّذ في النسخة الحالية

- **100 قالب فعلي** فريد المعرف من 20 هوية لونية × 5 تشكيلات فنية؛ تصنيف وبحث لثماني مناسبات، مع نصوص مبدئية مناسبة.
- محرر مباشر للأسماء والتاريخ والوقت والمكان والرسالة والقالب.
- أربع صياغات مقترحة محلياً، دون طلبات ذكاء اصطناعي خارجية.
- تصدير بطاقة PNG، وحفظ PDF عن طريق الطباعة.
- روابط المشاركة، QR، الخرائط، واتساب المنظّم، وتنزيل ملف تقويم ICS.
- لوحة دعواتي: حفظ/تعديل/نسخ/حذف/استيراد وتصدير JSON.
- صفحة داخل الموقع بعنوان «المسارات»، تفصل المنفذ عن المقترح.
- اختبارات GitHub Actions: سلامة 100 نموذج، صحة JavaScript وبنية الملفات.

## الحدود الأساسية

- المشروع **تجريبي يعمل بالتخزين المحلي**، ولا توجد حسابات سحابية أو إرسال تلقائي أو بوابة دفع أو قاعدة RSVP.
- **روابط المشاركة عامة لكل من يملكها** وتحمل البيانات النصية المضمنة. لا تضع فيها معلومات شخصية حساسة.
- بيانات الدعوات المحفوظة محلية للمتصفح؛ تصدير JSON وسيلة نسخ احتياطي وليست مزامنة آمنة.
- تصدير Canvas قريب من معاينة CSS لكنه ليس نسخة بصرية مطابقة حرفياً لكل تأثير.
- مكتبة QR والخطوط قد تتطلب إنترنت في أول تحميل.

## التشغيل محلياً

افتح `index.html` عبر خادم ملفات ثابت؛ مثال: `python3 -m http.server 8080`.

## الاختبارات

```sh
node --check assets/catalog.js
node --test tests/*.test.cjs
```

## GitHub Pages

يعمل النشر تلقائياً عند تعديل `index.html` أو `assets/**` أو `tests/**` أو الوثائق. إعداد **Settings → Pages → Source = GitHub Actions**.

تفاصيل التنفيذ ومقترحات التوسع: [PATHS.md](PATHS.md).

حقوق القوالب: ألوان وزخارف CSS ونصوص نموذجية صُنعت لهذا المشروع، دون استيراد مشاريع أو ملفات خاصة.

## مكتبة الستوري الجديدة (20 خلفية)

- رابط مباشر للمكتبة: https://q8-ux.github.io/dawat-platform/#/stories
- 20 خلفية مرسومة بصيغة SVG أصلية بأبعاد 1080 × 1920، تصنيف حسب المناسبة، معاينة واختيار من داخل استوديو التحرير.
- عند اختيار ستوري يمكن إدخال الاسم، والدعوة، والتاريخ، والموقع، وتصدير PNG فعلي بمقاس 1080 × 1920، وإنشاء رابط مشاركة.
- هذه الخلفيات **نسخ SVG فنية مستقلة** قريبة من الاتجاهات البصرية المعتمدة، وليست ملفات PNG المصوّرة التي جرى توليدها في المحادثة. يحتفظ المستخدم بالأصول المصوّرة الأصلية في حزمة ZIP منفصلة. لن ندّعي رفع الصور الأصلية قبل نقل ملفاتها الثنائية فعلياً.
- التخزين المحلي يعني أن صور الخلفيات العامة تظهر للجميع بينما بيانات المسودة لا تتزامن بين الأجهزة.
