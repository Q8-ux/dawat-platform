# دعوات | DAWAT

منصة ويب مستقلة لتصميم دعوات الأفراح والمناسبات بواجهة عربية RTL.

## ما يعمل
- 12 ثيماً أصلياً للبطاقة ومحرّر للبيانات مع معاينة فورية.
- أنواع مناسبات متعددة، تاريخ ووقت ومكان ورسالة الدعوة.
- تنزيل PNG وحفظ PDF عن طريق الطباعة.
- رابط مشاركة قابل للنسخ، خريطة Google / Apple Maps اختيارية، واتساب المنظّم، ورمز QR عند توفر مكتبة التوليد بالمتصفح.
- حفظ مسودات متعددة وتعديلها وحذفها في المتصفح نفسه باستخدام localStorage.
- استضافة ثابتة دون خادم أو حسابات أو تكاليف.

## الخصوصية والحدود
لا يوجد في النسخة الأولى تسجيل مستخدمين ولا قاعدة بيانات سحابية أو استقبال RSVP مركزي ولا دفع إلكتروني. رابط الدعوة يضم البيانات النصية داخل URL hash ويمكن لأي حامل للرابط الاطلاع عليها؛ لا تضف بيانات شخصية حساسة. التعديل بعد المشاركة يتطلب رابطاً جديداً. مكتبة QR تُحمّل من CDN وتولّد الرمز داخل المتصفح، ولا تُرسل بيانات الدعوة إلى خدمة إنشاء رموز خارجية.

## النشر
الموقع موجود في `index.html` ويُنشر بواسطة `.github/workflows/pages.yml`. لتفعيل النشر افتح **Settings → Pages → Build and deployment → Source → GitHub Actions**. بعدها شغّل **Actions → Publish DAWAT to GitHub Pages → Run workflow** إن لم يبدأ تلقائياً.

الصفحة المستهدفة بعد نجاح النشر: https://q8-ux.github.io/dawat-platform/

هذا المشروع مستقل ولا يستورد أي ملف من مشاريع أخرى.
